# Shivanikher Tech Vault

Personal knowledge base for architecture notes, tool evaluations, decisions, and code snippets.

## Structure

- `notes/architecture/` — system design and patterns
- `notes/tools/` — library and service evaluations
- `notes/decisions/` — ADRs and trade-off records
- `notes/snippets/` — reusable code fragments

## Usage

- Add a note with `/vault-entry` in Cursor
- Conventions are in [`CLAUDE.md`](CLAUDE.md)
